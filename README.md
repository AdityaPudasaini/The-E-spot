# The E-Spot – Jasun Branch
 
A Nepal-based reselling web application that connects buyers and sellers of pre-owned products, promoting sustainable commerce and circular economy within the local community.
 
---
 
## About This Branch
 
This branch is maintained by **Jasun Maharjan** and contains the following contributions:
 
- About Page – Mission, Vision, Core Values, and Our Story sections
- Product Listing Page – Browse pre-owned products with a responsive grid layout
- Header and Footer components with navigation links
- User authentication (Login, Register, Update Profile)
- Database integration for product and user data
